# Shiftzy Go

Shiftzy Go is a vehicle shifting and travel-connect platform built in Replit. It helps people move vehicles between locations by connecting vehicle owners with travelers or transport options in a simple, organized way.

## About the Project

Shiftzy Go is designed to make vehicle shifting easier by offering a clear flow for:

* posting a vehicle shifting request,
* checking available travel or transport options,
* entering vehicle details such as registration, RC, insurance, and photos,
* managing local and long-distance shifting needs.

This project was built as a practical web app prototype for real-world vehicle transfer use cases.

## Features

* Vehicle shifting request form
* Local and intercity shifting support
* Pickup and drop details
* Vehicle information entry
* Registration and document details
* Insurance expiry tracking
* Photo upload support
* Simple user-friendly interface
* Built and tested in Replit

## Use Cases

Shiftzy Go can be used for:

* shifting a car or bike within a city
* transferring a vehicle to another district or state
* connecting vehicle owners with travelers or transport helpers
* exploring a future marketplace for vehicle shifting services

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/selvin24-tech/VehicleShiftMate-SHIFTZY-GO.git
cd VehicleShiftMate-SHIFTZY-GO
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the app

```bash
npm run dev
```

If your project uses a different start command in Replit, use that command instead.
